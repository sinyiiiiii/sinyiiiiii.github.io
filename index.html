Projects

Plant Disease Detection and Severity Classification App

Individual project · Degree Final Year Project

A mobile app that identifies a plant and its disease from a photo, measures how severe the disease is, and returns AI-generated treatment advice.

What I built

  • End-to-end system: a React Native app and a Django backend in a client-server architecture. Heavy model inference runs on the server, so the app stays smooth on any phone.
  • Model selection: designed and compared several CNN architectures. Final choice: EfficientNetB0 for plant species classification and EfficientNetV2S for disease detection, reaching 98–100% accuracy in testing.
  • Severity measurement: combined rembg, GrabCut and adaptive colour thresholding (LAB/HSV) to calculate the Percentage of Diseased Surface (PDS), then graded severity from that value.
  • LLM integration: GPT-4o-mini turns the detected plant, disease and severity into structured JSON treatment and prevention advice.

Cross-Lingual Sentiment Analysis of E-Commerce Delivery Experiences

Group project · Natural Language Processing · Data Collection

A team project analysing delivery experiences in Lazada Malaysia reviews for skincare, home appliances and beverages, including mixed English–Malay text.

What I built

  • Selenium scraper: takes a search keyword per category, finds the products, and collects reviews across all five star filters and every page.
  • Bot-detection handling: custom user-agent, hidden navigator.webdriver flag, random delays, and manual login so no credentials sit in the code.
  • Clean output: filters out junk, seller replies and duplicates, then saves an Excel file with one sheet per category (review text, date, aspect).

Team outcome (modelling by my teammates)

XLM-RoBERTa fine-tuned for delivery sentiment, plus zero-shot BART-MNLI for product category. Reported 99.02% accuracy and macro F1.
